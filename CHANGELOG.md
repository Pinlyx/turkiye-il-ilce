# Changelog

## 0.1.0 - 2026-11-20

- First release.
- `lookup(lat, lon)`, `iller()`, `ilceler(il)`, `data_info()` and the `il-ilce` command.
- Boundary data built from Overture Maps release 2026-11-18.0: 81 provinces, 973 districts, simplified to about 7.8 MB.
- `scripts/build_data.py` rebuilds the data from the newest Overture release.
